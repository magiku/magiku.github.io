C07【kindle】记录一下对kindle_KPW4的越狱与插件安装

发表于2026-08-24|更新于2026-08-24|折腾/运维案例

差不多十年前，做了个教程：【kindle】如何用kindle观看漫画（自制mobi格式漫画与网站直接下载）_哔哩哔哩_bilibili

最近找到它了，想着把它越狱了吧，顺便记录一下。

kindle越狱记录

越狱教程来源：KindleModding - WinterBreak

该方法利用了 Kindle 商店的缓存漏洞。当正常访问 Kindle 商店时，根目录会出现 .active_content_sandbox 文件夹，里面会出现缓存页面。此时开启飞行模式会阻止 Kindle 商店修改我们将要替换的特制缓存文件。

待我们替换完文件后重启 Kindle以重置 Kindle 商店相关的内存状态，再次访问商店时就可以让 Kindle 商店访问特制页面并执行越狱了。

越狱准备

必备条件：

  • 一台电脑用以访问kindle的存储目录执行文件修改。
  • kindle已注册亚马逊账号并可正常访问商店。
  • 一根数据线（本来是很普通的事，但现在找个microUSB的可传数据的线不容易）
  • 可流畅访问GitHub的网络

预防更新：

  • 为避免越狱过程中触发kindle的系统更新：用电脑连接kindle，删除根目录下所有的update开头的文件；再往kindle塞一些文件，确保剩余空间不足100M，避免又下载了更新包。

下载越狱用的文件：Releases · KindleModding/WinterBreak

  • 可解压出三个文件夹：
    • .active_content_sandbox/
    • apps/
    • mesquito/

越狱过程

  • 电脑用数据线连接kindle，检查当前根目录下是否有.active_content_sandbox文件夹。

    • 如果有，直接删除，并退出连接重启kindle。

  • 确认没有之后，拔掉数据线，kindle打开Wi-Fi浏览一下商店，下载阅读免费书籍，然后打开飞行模式。

    电脑再次用数据线连接kindle，检查当前根目录下是否有.active_content_sandbox文件夹。

    打开.active_content_sandbox\store\resource\LocalStorage并删除其中的文件。

    如果Wi-Fi打不开商店，也没有文件夹产生，没事。个人亲测，可以直接开始下一步，最后也能越狱成功。

    （毕竟原作者写的重置kindle的操作里也没有正常打开商店，生成文件夹的步骤。）

  • 将之前从WinterBreak中解压出的文件拷贝进kindle根目录，覆盖。

  • 弹出 Kindle 磁盘并拔掉 USB 数据线。

  • 重启kindle（从设备设置里点击重启，这一步必须做）

  • 进入商城，待提示需要关闭飞行模式时，选择【好的】。

  • 此时会进入WinterBreak的界面，点击图片。

  • 稍等一会，越狱就成功了（会自动重启）。

如果以上操作无法越狱，可以尝试以下操作（连接电脑跟断开连接的操作就不说了）：

  • 重置kindle，恢复出厂设置。
  • 将之前从WinterBreak中解压出的文件拷贝进kindle根目录。
  • 登录kindle账户，并马上打开飞行模式。
  • 确保.active_content_sandbox\store\resource\LocalStorage文件夹不存在或内部无文件。
  • 重启kindle。
  • 进入商城，待提示需要关闭飞行模式时，选择【好的】。

越狱之后：

  • 之前的.active_content_sandbox文件夹可以删除了，然后如果根目录下有cvm_xxxxxx.core文件，可以删除，这是日志文件。
  • document文件夹下如果有新文件与文件夹也可以删除。
  • 之前塞的文件以防止更新的“垃圾文件”也可以删除了。
  • 日常保持飞行模式，防止系统更新，也可以自行搜索禁止kindle更新的教程。

越狱完推荐的软件

MRPI与KUAL是必装的，前者是mod管理器，后者是mod基础模组。

MobileRead Package Installer (MRPI) — 插件安装器

MobileRead Package Installer 是一款 KUAL 插件。因为现在 Kindle 固件不支持直接把插件文件以刷入 bin 的方式安装，所以需要通过 KUAL 的这个插件 MRPI 来安装。

下载：[Tools Snapshots of NiLuJe’s hacks - MobileRead Forums](https://www.mobileread.com/forums/showthread.php?t=225030#:~:text=MR Package Installer)

  • 找到KUAL & KUAL extensions:
  • 选择最上面的MR Package Installer | kual-mrinstaller-x.x.x-rxxxxx.tar.xz

安装：

  • 把下载好的压缩包解压缩得到两个文件夹：extensions 和 mrpackages
  • 将文件夹拷贝到 Kindle 的根目录

KUAL — 插件程序启动器

KUAL (即 Kindle Unified Application Launcher)，是一款插件启动器。

安装 KUAL 之后，你可以下载或自己编写插件并通过 KUAL 启动。比如用来启动 Koreader 之类的插件程序、让电量显示百分比等。

下载：Tools Snapshots of NiLuJe’s hacks - MobileRead Forums

  • 找到KUAL & KUAL extensions:
  • 注意下载自己kindle型号相对应的软件版本，我是KPW4，所以要下载KUAL (coplate) | KUAL-xxxxx-202xxxxx.tar.xz

安装

  • 将解压出来的Update_KUALBooklet_xxxx_install.bin拷贝到mrpackages文件夹中。

  • 弹出kindle，在kindle主页的搜索框中输入 ;log mrpi 点击回车。

  • 这时会弹出一个纸箱的图标（MRPI），然后kindle会自动重启以安装KUAL。

  • 成功安装 KUAL 后，我的图书馆中会出现一个名为 KUAL 的个人文档图标，正常情况下，点开此图标会显示菜单。

KOReader

Koreader 这款软件采用图像分割再重排的方式处理 PDF 文档（包括扫描和非扫描页面），这样不仅支持文字版 PDF 重排和数学公式的重排，还能对扫描版 PDF 和 DJVU 文档进行重新排版。重新排版后的文档，文字放大后可以适应屏幕自动换行，免去不断地左右拖动页面阅读。

另外安装 KPVBooklet，可以在Kindle 中直接显示原生系统不支持的 EPUB 等格式，并将其打开方式自动关联到 Koreader。

可以说，越狱就是为了安装它。

下载Koreader：

Releases · koreader 提供了三种版本，对应不同的 Kindle 设备型号，请按需选择：

  • Legacy：K2、DX、K3（及其它差异化版本）
  • Kindle：K4、K5、KPW1
  • PW2：KPW2 后的所有版本（如 Kindle 7/8/10、KPW 2/3/4/5、KO 1/2/3、KV）

安装Koreader：

  • 将解压出来的extensions 和 koreader 两个文件夹拷贝到kindle的根目录。

    注意：一定不要装汉化！！容易出bug！阅读界面有中文的，外侧也就start、stop而已。而ASAP表示不休眠。

  • 弹出kindle，打开KUAL电子书，在菜单里启动菜单中启动 Koreader 并用它的文件浏览器打开并阅读电子书。

下载KPVBooklet：Releases · koreader/kpvbooklet

需要注意KPVBooklet 2018年就没有更新了，你的机子如果最近几年更新了，那么很大概率会不兼容这个插件。

安装KPVBooklet：

  • 将解压出来的update_kpvbooklet_xxx_install.bin 拷贝到 Kindle 里 mrpackages 文件夹中
  • 弹出kindle，在kindle主页的搜索框中输入 ;log mrpi 点击回车。
  • 等待安装与重启。

但kindle贫弱的性能，还是不支持对几百页的pdf进行重排，阅读一会儿Koreader就会闪退。。

用处主要还是可以看epub（虽然也可以用工具把epub转换成mobi再导入kindle里。。）

每次阅读完，记得退出Koreader，以保证续航。

实话说，在家里用平板阅读体验会更好，出门手机方便单手握持。kindle现在纯属折腾玩。未来看看海信的新墨水屏手机如何吧。

如果要卸载，Koreader直接删除两个文件夹即可，KPVBooklet要把压缩包里对应的uninstall.bin按安装流畅装一遍（实际是卸载）。

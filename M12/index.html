M12【旧文收束总结】在复杂的世界中保持主体性——不盲信、不内耗、不越界

发表于2026-08-11|更新于2026-10-18|个人杂谈

我过去的几篇杂谈文章其实一直有这么条核心理论：

世界是复杂的，知识与理论模型是片面的，我们需要对其不断更新。不试图以一种模型解释一切，不对某一理论保持绝对迷信。

不过我之前的文章，甚至连我自己都没有把握好一个度——过度思考与反思，陷入自我反刍，导致内耗。

现在我认为需要再为这个理论加一个限制：思考的最后一定要回归现实，能与现实产生互动。

我一直保持着不成为某个理论、某个主义的教徒，它们只会是我的工具，我需要时使用，不好用或不需要时就更换其他工具。

也是基于此思想，我其实一直时不时在修改过往的文章，不过这次我觉得要不试试不改以前的文章了，它们或许个别地方还不严谨，但正是存在不严谨的地方才让行文有感情，不晦涩。如果最后修改成了教材一般的文本，反而会失去原本“科普”的意味。

这次，我会在本文对过去的文章做一个总结与校对，也是对外展示我如何实践自己的人生哲学。同时，这些文章也需要被串起来，它们其实并不是彼此孤立的单篇。

旧文章总结

以下按文章进行回溯总结与提炼，新读者可跟着点进链接看一下旧文章的内容。

这些旧文章本质是我的人生哲学在不同具体领域的应用。

用不同的领域作为例子，反复展示同一套认知——不盲信、不固化、多视角、可更新。

在本文后续则强调这套认知的重点：把握适用范围与回到现实。

文本认知

M03【语言的失真】文字沟通为什么会“变味”：失真的机制与修补方式

在这篇文章里我建立了一个语言认知的链条：思维 → 语言编码 → 文字 → 他人解码 → 他人的认知重建

并强调这个链条的每个环节都有可能存在认知偏差。

在介绍这个链条时，采用了分层结构，就像计算机网络一样。

  1. 在符号层，强调每个人对词汇与词义的映射关系并不完全相同。（专业点说，就是能指与所指之间的对应关系不同）
  2. 在语用层，强调词汇被广泛使用的过程中会染上其他的含义，最终导致“说者无心、听者有意”（即能指链滑动）
  3. 在认知层，强调说者的思想是根据他当前的情景、思维、语言能力与词汇理解编码为文字的；听者根据他自己的思维、语言能力、词汇理解以及对说者所处情景的揣测去解码文字的。这一来一回就产生了原意与理解之间的错位。

注意到这些导致原意与理解错位的因素，我们就可以对各项因素进行控制，让对话变得轻松高效，让误解更少。

  1. 说者要补充上下文，要注意用语是否容易引起误解。
  2. 听者要进行二次确认，必要时询问更多的细节。

文字的存在、思想的编译，具有正向意义。在试图将思想编译为文字时，我们就是在对自己的思想进行一次整理，这种整理可以让我们把一些模模糊糊的感觉变得清晰，对一些似懂非懂的知识进行查漏补缺甚至进行更进一步的升华（就好像在稿纸上进行数学计算，公式推理）。

比如一些文学作品常会有这样的情节，一个拥有自我意识的人/物，经过一系列事件后，想起了某段对话才开始领悟到“原来我一直感受到的那种情感是‘爱’啊”；或者说对其他人询问“我一直持有的这种感觉到底是什么”。

这就是文字参与进思考，让主体把模模糊糊的感觉变得清晰，使自己更了解自己。

更严肃一点的话，不少自杀的人留下的遗书，常会有这么一段话在表达自己总有一种很难受的感觉，但不知道是什么，也无法抑制。我们看到这类遗书会遗憾，其中一种原因就是我们认为他的自杀是可以避免的。

M04【语言的失真】学习时别抠字眼

这篇是介绍 M03 的理论在学习上的实践，核心观点是：学习的目标应该是建立自己的体系与知识结构，不要盲目地照搬与复刻作者。

也就是强调我们学习的目标是对他的知识取其精华去其糟粕，而不是去模仿一个人/一本书。

这里再插入一点我个人的感叹：现在不少文化作品——漫画、小说、游戏或短视频，它们融合了很多梗、抖了很多包袱、借鉴了很多其他作品，但没有自己的特色，没有自己的东西。这样的东西或许会一时爆热门，但也只是昙花一现，大家笑一笑，传一传。回头过段时间就发现没啥意思了，这个作品也就淡出了人们的视野。

我们在阅读学习时要去挖掘深层的内容，即去理解脱离文字之外，作者真正想表达什么，让你理解什么。

这样你才能接触到知识本身，而不只是作者的话。

我见过很多人讲得头头是道，随便就能背出各种名人名言，各种金句；但其中不少人也只是会背，却没有在生活中实践。

甚至很多人学习的时候会陷入：

老师这么说。
书上这么写。
视频作者又这么说。
百科又不是这么写的。

然后开始纠结到底哪句话才是正确答案。

很多时候，问题不在于“对与错”，而在于不同的观点是在什么情景下说的，是在解释什么，是默认适用于什么场景，使用的词汇含义是否存在偏差等等。

在M10【咖啡】聊聊咖啡与我对入门咖啡的建议一文中，我就强调了事物不一定存在标准答案，也强调咖啡的冲煮技巧要从萃取原理去理解，否则很多观点看起来像是互相打架的。

在M01【方法论】从哲学说起：我如何怀疑、如何更新

提到了这么一个关于汤泡饭的误区：
“不能吃汤泡饭”——这个观点的产生原因是汤泡饭使得米饭好入口后，很多人便减少了咀嚼次数甚至直接就着汤把米饭喝下去，这样就容易消化不良。了解这个观点的“发生学”后，我们就知道了汤泡饭是可以吃的，只要你保持咀嚼次数。

也提到过去对植脂末、人造奶油等加工植物油的排斥是因为技术不成熟，会产生大量反式脂肪，而现在技术成熟后，做到完全氢化的植物油就不再含反式脂肪了。坏的是反式脂肪，而不是加工植物油。（而反式脂肪的产生条件还有高温，油炸和烧烤类食物中也会含有大量反式脂肪，这一点反而少被大众意识到）

对于阅读与学习，我个人的一个习惯是试着拆掉一个看似理所当然的结论 → 找到它隐含的前提 → 检查推理过程 → 建立更可靠的模型 → 再试着用这个模型解释现实。另外就是试着与其他我已掌握的理论和模型做联系，是否相似，能否融合。

思维认知

M05【思维转变】人之所以为人：选择与思考

这一篇信息量很多，是把各种观点都硬塞在一起的，探讨的是这些内容：

  • 人能控制什么、不能控制什么；
  • 不要把复杂系统人格化；
  • 不要把有限样本当普遍规律；
  • 不要把自己的体验投射给别人；
  • 不要被即时刺激牵着走；
  • 不要把别人提供的答案当成自己的答案；
  • 不要停止思考；
  • 要反思自己默认接受的前提。

核心总结就是不要让未经检查的认知模型替你思考。

这篇更主要的落脚点是批判网络上的站队现象——以偏概全、贴标签、完全美化/完全抹黑。

以及强调不要简单相信这些言论，影响自己的判断，避免盲目从众——“三人成虎”。

我认为人的一个重要能力就是能够不完全按照即时本能行动，能够对未来、因果、规则和抽象模型进行思考后，再去选择如何行动。

M01【方法论】从哲学说起：我如何怀疑、如何更新

这篇介绍了我对哲学的理解，并提出一个给自己的思维认知系统迭代升级的方法论。

着重强调我们可以暂时接受一个理论模型，但不能把它当成永恒真理。

但也需要注意理论模型常具备一些前提假设，我们不可能要求所有东西都是完全可证、完全正确的，我们常需要容忍这些前提的存在。

我们无法证明太阳明天一定还会升起来，住的房子一定不会倒塌，地球不会突然爆炸，自己下一刻一定还活着；但我们会去相信确实如此。

我们的目标是让前提更少，更简洁，更科学。

方法论：怀疑 → 觉察 → 悬置 → 体验 → 追问 → 整合 → 更新

  • 怀疑与觉察，让我们发现自己存在的，长期未被审视更新的旧认知。

  • 悬置与体验，体验并不会自动产生客观结果，但可以纠正自己的主观预设。

    • 常有人会因为听说什么东西不好，就拒绝使用那个东西。但有时你就是得悬置一下这种主观预设，自己去体验一下，才能得出相对客观的结果，而不是人云亦云。
    • 但怎么体验、带着什么认知去体验，感受会完全不同。比如同一个作品，你在一段时间后去重温，常会有别的新发现、新感受。
    • 所以只能说是“得出相对客观的结果”。

  • 追问，即分析其发生学——为什么产生，如何产生，产生了是为了什么。

  • 整合与更新，把经过体验后的感受与追问得到的逻辑链条，和原来的旧认知结合在一起，去伪存真。

更全面一点的总结就是：多用一阶反思代替前反思，多用二阶反思更新自己的逻辑思维与旧有知识。

前反思：没有经过深层思考，仅调用自身经验与记忆去得出结论
一阶反思：思考前反思得出的结论是否正确
二阶反思：思考自己为什么这样思考（包括前反思、一阶反思和二阶反思）

在文章的【哲学之后】部分，还强调了三个实践的维度：

  • 与人：人际交往背后常有不同的立场，我们需要去识别这些立场，不能只把握“求真”这个立场。人们的立场可能是表达情绪/寻找同伴/寻求安慰/宣泄情绪。我们需要去理解语言背后的行为，甚至允许自己参与到这种不求真的活动中。
  • 与世：不要简单归因，不要把复杂、动态、多维的对象压扁成一个静态标签；多去欣赏与体验这个世界。
  • 与己：要能整合对复杂、动态、多维的对象的印象与情感，不单一化——喜欢≠对方完美无缺，讨厌≠对方一无是处；也不要因此一直试图证明后者，有时你只需承认且表达前者就够了。

理论认知

M02【心理学】心理学是伪科学吗？——伪科学的定义是什么，有哪些伪科学？

以上所有的文章都是在告诉读者要更新认知，要更新知识；那么对于新知识、新理论，我们又该怎么判断它可不可靠？

这篇文章虽然当时标题叫作“心理学是伪科学吗”，讲的是什么样的证据才值得相信。

一个理论的可靠程度可以从高到低分为：

已充分验证
有较强证据支持
部分支持
存在争议
尚缺乏证据
目前无法检验
原则上不可检验

这些状态不能被简单压扁成：科学 / 伪科学。

在 M05 中，我说对于一个命题，我们可以找到10篇论文是支持的，也能找到10篇论文是反对的（比如代糖是否有害），我们不能仅凭其中某几篇就盖棺定论。

正确的做法是分析论文的证据性，从实验方法、实验规模、实验的执行条件、实验是否可重复可验证等方面综合考量。

关于实验，一个过于简化的证据等级如下（从高到低）：

系统评价 / 荟萃分析（把多个随机对照试验汇总起来看）
随机对照试验（双盲只是控制偏倚的手段，不是单独的一级）
非随机的对照试验
观察性研究（队列研究、病例对照研究、横断面调查）
动物实验、体外细胞实验

“临床研究”是个笼统的说法，本身不构成一个等级——上面几层只要是在人身上做的，都算临床研究。

谨记：

  • 小鼠等动物实验 ≠ 人类结论
  • 相关 ≠ 因果
  • 单一指标 ≠ 整个生理/心理现象
  • 单篇论文 ≠ 科学共识
  • 最新研究 ≠ 推翻过去研究 ≠ 最可信最权威的研究

当然，不是什么知识观点都有论文可查，都需要论文支持。

所以文章更多是在讲：对于一个知识点，我们要考量它的理论支撑、它的逻辑推理过程、它的适用范围。

我们要识别出一个观点是否存在以下谬误：

  • 相关/伴随指标 → 被偷换成原因
  • 结果变量 → 被偷换成原因变量
  • 复杂的情境依赖系统 → 被压缩成单一功能标签
  • 多变量系统 → 单因果叙事
  • 跨层级/跨领域/跨范畴的结论外推

心理认知

M06【精神分析】那个总说“你不够好”的声音，从哪来

这篇文章是面向普通人的精神分析启蒙 + 一套自我观察方法。包括后面会提到的另一篇精神分析文章，其实都是我理解、扬弃之后的精神分析，甚至可以不叫精神分析这个名字了。

我从来不是一个原教旨主义者，在这里我把原本复杂的精神分析理论改造成一个我自己觉得好用的模型，这一点得说明白。

哲学核心依旧没变，并将其挪用到了心理层面上：不要把自己的心理反应当成天经地义，要寻找它是怎么形成的。

我简单地借用了弗洛伊德的本我—自我—超我模型，用它来解释我们内心的纠结：

本我：“我想要怎么做”
自我：“我决定怎么做”
超我：“我应该怎么做”

它们只是一个便于理解内心纠结的解释性工具，并非真实存在的心灵结构与实体，后续要介绍的就是它们的产生与作用机制。

“我应该怎么做”不一定真的是源自我们自己的想法，我们要去探寻我们怎么有这种价值观、道德观。

它们可能来自父母的要求、学校的要求、社会评价、同龄人压力、自己过去形成的规则以及真正属于自己的价值判断。

再接着探讨一个人的行为逻辑与思维定势。性格确实是多方因素导致的，我们无法改变先天条件，但我们可以去改变后天的因素。一个人在成长过程中，寻找与周遭环境最匹配的生存模式后，逐渐固化下来的防御机制会影响人的性格。

这在我身上就是如此，我小时候习惯于采取沉默不语、暗暗观察、降低自我存在感的方式去避免吵架与迁怒。这很有效，于是直到现在，我已经习惯于独来独往，一整天可以不说一句话，对人的情绪与行为十分敏感，洞察人心。但也是这种敏感与习惯性回避，让我至今没有一个知心朋友，与父母的关系也很疏远。

文章介绍了各种防御机制，其实就是回应了 M03 的理论——我们认识了可以表达的词汇与术语，可以把自己模模糊糊的感觉和感受变得清晰，从而可以被标记与觉察。

只有这样，我们才有可能使用那套[怀疑 → 觉察 → 悬置 → 体验 → 追问 → 整合 → 更新]的方法论去试着意识和改变自己当前的行动。

这样一点点觉察与长期调整反馈，才有可能改变自己行为逻辑、思维定势。

再往后的内容就是介绍一些常见的容易影响我们价值判断，让我们产生“我应该怎么做”的社会现象，包括：

代际创伤
实用主义
集体主义
边界模糊
对个性的矛盾态度
非此即彼的二极管思维
对权威的复杂心态
孝道
结果导向
对精神需求的低估与回避

随后推荐了几本描述中国社会文化现象的书，且强调对社会现象的谈论，不要滑坡到民族劣根性的谬误中。

这几本书描述的内容也是提供给各位一个可被标记，被觉察的锚点；我不是一个社会学家，这部分我写得不太好，不怎么严谨，请各位批判性地阅读吧。

欲望认知

M07【精神分析】你必须享乐：一条让人焦虑的现代命令

上一篇更多是对于自我的剖析，这一篇则是进一步剖析，去探讨那个影响我的外界是怎么样的。

当然这篇文章内容依旧是经过我魔改简化后的，严格来说它应该是 magiku 派精神分析。

人是存在于世，生活于社会当中的，想了解自己，不能只谈自己，也需要了解个体与社会之间的结构关系。

这篇文章的核心在于探讨“欲望”；你的欲望是源于你自身的，还是社会告诉你的？

在我们的生命早期，“父之名”的出现，让我们把焦点从母亲身上挪到了社会上。

可随着我们成长，我们接触到当代社会盛行的消费主义与精英主义；我们被告知你可以拥有更多，你应该拥有更多，你没得到就是你不够精英，你不够努力；我们甚至可能因为自己无法获得别人声称应该获得的快乐，而怀疑自己是不是有问题。

这篇文章就是想告诉读者：

你现在的欲望可能不是天然的。
你现在追求的成功可能不是你自己定义的。
你现在追求的美可能不是你自己定义的。
你现在认为“应该快乐”，也可能不是你自己决定的。

其中有一节专门谈性别对立。我的看法是：性别只是最省力的那个分类——身体一眼可见，二分看起来天然，而且你每天都在跟另一半人类打交道，没法靠“不看新闻”躲开。分类越省事、接触越频繁，它就越容易被拿来当缺失的出口。

把结构性的委屈算到对面那一类人头上，这才是问题所在。收入、外貌、谁付出得多，这些指标全是相对的——你高一点，就必然有人低一点。在那把尺子的坐标系里，对面的人天然就是威胁。

同一套机制放大到更大的尺度，就是“仇恨一个敌国”。那一节里我给了个很朴素的判断办法：看它需不需要证据。需要证据的，是争端；不需要证据就成立的，是信念。

至于“性化位置”，它是主体与欲望结构的关系，不是生理性别。“男人就该有男人的样子”“女人要有女人味”这类话，都只是把一个位置焊死在了身体上。

还有一类常见操作：热点事件一出来，先锁定当事人的性别，然后宣布“事情就是因为 ta 是这个性别”。这就是我一直在批的简单归因、标签扁平化。比起性别，更该看的是背后的社会现象、当事人的心理状态、家庭背景、法治是否缺失。

现在还有一种新的风向，出现神人神事后，网友们就开始检索相关人员的背景，只要发现谁跟“武汉大学”这个标签相关，就直接宣布“破案了”，“那就不奇怪了”。

这篇不给“怎么活”的答案。它想做的只是让你看清自己那些“应该”是从哪来的——看清之后，选什么还是你自己的事。

主体被解放出来之后，我们就面临上世纪存在主义者们所面临的处境——如果上帝死了，没有人替你保证意义，没有人替你指明道路，没有人为你的人生进行裁判，你要怎么做怎么办？

一点个人私货，推荐一部动漫《异国日记》，讲的是一位初三女学生在父母因车祸过世后，被小姨领养，但小姨担心自己的言行会影响女孩未来的人生；因而有意识地保持精神上的疏远，不去深入对方内心，也不为对方指明该做什么，该以什么为目标。女孩离开了一向控制欲极强的母亲，突然得到了“自由”，陷入了迷茫。故事就开始这么一步步展开了，讲述女孩如何在这种情景下开始思考自己的人生，如何逐渐适应了小姨家和高中生活。而小姨也因为女孩的介入，从孤僻的、与人保持社交距离的家里蹲小说家开始变得柔和，也在心里与那个控制欲极强的姐姐和解了。

（更进一步的私货就是这个小姨与我很相似，都是大脑一刻不停的总在思考各种事情，也会因为担心影响别人的人生而保持社交距离，也是从小时候的还算健谈到成年后的可以一天不说一句话，手机消息也常不及时回复。）

再一点私货，我现在很喜欢“鸣潮”这个游戏，其中一点原因就是它的故事内核是在探讨这些内容。

社会认知

M08【社会学】读罗萨，谈在加速的世界里，如何真正地活着

这篇跟前面几篇不太一样，是先有了理论框架，再回头去认领自己的体验。读罗萨的时候我一直在对号：时间被切成碎片，一天忙完想不起干了什么，躺不平也卷不动，住在大城市里却谁也不认识。

他拆得比我细。科技加速、社会变迁加速、生活节奏加速，这三样互相咬合，像一台机器——科技让事情变快，事情变快就逼着生活节奏跟着快，生活节奏一快又反过来要求科技继续加速。谁都被推着走，但没人负责开这台机器。

推它的两股力，一个是竞争，一个是“应许”。竞争好懂；应许是那种承诺——只要你再快一点，就能过上更好的生活。这个承诺永远不兑现，但一直有效。

后面他讲关系异化，分空间、物界、行动、时间、自我五层。我记得最深的是物界那一层：东西越来越多，跟东西的关系越来越浅，手机换得比朋友还勤。

他的出路是共鸣：被触动、有回应、能转变、不受掌控。最后一条最要紧——共鸣发生在你控制不了的关系里，能计算、能预测、能控制的那种关系，罗萨说那就又变回任务清单了。

但这篇我没有停在共鸣上。共鸣回答的是“我有没有真的活在这些事里面”，它回答不了劳动法、住房、医疗、教育。把加速的困境归到“你不够共鸣”，等于拿心理问题盖住结构问题。

所以后面我写了两层：制度批判归制度批判，个体能做的是降低结构对自己的压迫——少背债、留应急金、保住身体和转行的能力。这些不解决结构，但能让人在被压着的时候还有点余地。

人际关系处理

M09【分享与索取】分享者与索取者，本来不是对立的两方

这篇从一个很具体的场景开始：发完一篇东西，底下全是“这个软件叫什么”“能不能帮我看看我这台为什么连不上”，而答案就在刚发的视频里。

写的人花几个小时，读的人花十几分钟。这个时间差本身不亏——写的过程也在整理自己的想法。但写完之后还想拿点别的：有没有人读进去了，有没有人接着往下吵。期待高低跟投入走，随手转发一条和做一整套解答，心里的那条线不一样。

数据是后来多出来的一个回报来源。阅读量、点赞、完播率，反馈快到能当奖励用。麻烦在它是随机的：同一种内容今天推十万，明天推两百，找不到因果，只能不停试。老虎机靠的也是这个。

另一头，提问变得很便宜。学校里问题有标准答案，答案有老师免费给，于是“遇到问题先问人”成了默认动作。进了社会还这么干，短期是赚的：问的人付出打字和等待，答的人要读懂问题、回忆解法、组织语言、应付追问，实时、高耗能、不能并行。同一个问题发五个群，总有一个能白拿到答案。

长期看就是账户只取不存。被消耗过几次的人不会彻底不说，只是换一种更省的方式：缩小范围、把重复的问题写成 FAQ、只给方向不给答案、把边界写清楚。

这篇没有站在分享者那边骂索取者。它最后落得很平：两边算的账不一样，一边算这一次，另一边算长期。把两本账摆到一起，火气会小一些。

写完这篇我其实有点动摇，下面补充里说。

补充

对于人际关系的处理这一方面，我一直保持这种价值计算与对内理性反思；这反而让我把人际交往变成一本本人情账本，今天我欠谁一个怎么样的人情，昨天我为谁付出了多少需要回收多少人情才够抵消。

这当中最重的一笔自然是父母的恩情，这种计算方式下，父母养育了我前半生，这得花后半生去还。而这种亏欠感、愧疚感，使得我在与父母沟通交往时处于一种巨大的压力之下；而这种压力就使得我与父母之间存在着隔阂，无法好好交流和“真心换真心”。

在家庭之外的生活中，因为这种理念，很少会请求他人的帮助，凡事尽量靠自己；需要帮助时，总会很快想办法补偿回去，避免负债的存在；但这种行为常被认为不合群和不够哥们。

甚至在线多人游戏里，坑了都觉得很不好意思，这也导致我绝不主动玩多人游戏。

因此，对于人际关系这块，我不值得被学习，各位需要以我为戒，把握这种成本计算的度。

经验认知

M11【套】现成的解释是怎么替代思考的

前面几节反复说“不要用单一模型解释一切”，那是从理论这一侧讲的。反过来看：手里没有模型的人，也有一套现成的东西——词、分类、句式、别人嚼过的结论。看到事情先归类，再调出对应解释，结论就有了。这个过程比调用一个理论快得多，也隐蔽得多。

我管它叫“套”。这篇拆的是它怎么长出来、为什么在网上长得特别快、为什么很难被现实推翻，以及还有没有办法让它接受修正。

文章里还分了一个区别：直接经验和媒介经验。两者最后都会变成“我见过”“我知道”，但媒介经验可能从一开始就是筛选、剪辑、加工过的。重复足够多次，它照样进记忆，变成“过去发生过的事”。

模型的适用范围与合理应用

综上，我过往的杂谈文章，核心观点始终都是要多思考，主观上不完全相信任何一种理论，世界是复杂的，不试图、也不赞同把事物扁平化地理解与归因，要保持认知更新。

也是在聊人为什么会把一个复杂的东西，压缩成一个看似理所当然的观点/模型？

但因为我不想一篇文章写一句话就叠一层甲，所以从行文上看，我有不少地方单独拎出来是不严谨、绝对化的言论，我不少文章片段可以说本身也是犯了上面这个错误。

因此我才把对文本的理解作为这个系列的首篇，我相信各位应该能有自己的理解，也支持各位以审视辩证的角度去看我的文章，这也才能得到属于你自己的东西。

这次，在这篇文章中我要新提出一个补充说明：一个模型是具有其适用范围的。

我在上文的人际关系处理——补充里说了，我这套反思系统用在人际关系上容易带来内耗；另外我也在 M01 的哲学之后部分着重强调了在其他维度上要怎么做（也就是说，不能一律只用反思系统）。

在本文的前言也如此写道：

保持着不成为某个理论、某个主义的教徒，它们只会是我的工具，我需要时使用，不好用或不需要时就更换其他工具。

很多理论模型在刚提出时，是开创性的、颠覆性的、精准性极强的，可当人们试图用它解释一切时，就不得不为它打补丁了，最后导致原本简洁好用的模型变得臃肿，也变得模糊（模糊有利于“怎么都能解释”）。

而理论模型的提出常常是从非单一的现象/问题中推演出来的，所以市面上实际存在着多种基于同类现象/问题推演出的其他理论模型。它们可能是相似的，也可能是相对立的。

不过这些相对立的理论常常表面看上去互相反对，但仔细看会发现，它们有时候其实是在描述同一个东西的不同方面。

我们想全面地认识事物，最好就是不只使用一种模型解释一切，有时看看其他模型是怎么解释的，可以从不同视角了解到更多。

最终还是要考察证据、逻辑、适用范围和预测/解释能力。

假设一杯咖啡卖30元，你可以同时用不同模型解释：

  • 马克思的劳动价值论：

    • 生产这杯咖啡需要多少社会必要劳动？
    • 资本投入是多少？
    • 剩余价值在哪里产生？
    • 劳动与资本如何分配？

  • 新古典经济学：

    • 消费者愿意为这杯咖啡支付多少？
    • 它的边际效用是多少？
    • 供给曲线是什么？
    • 需求曲线是什么？
    • 最终均衡价格是多少？

  • 制度经济学：

    • 为什么消费者愿意相信这家店？
    • 为什么这家店拥有经营许可？
    • 为什么货币可以作为支付手段？
    • 为什么合同可以执行？

  • 行为经济学：

    • 消费者是不是受到锚定、品牌效应、从众、稀缺性、心理账户等方面的影响？

  • 信息经济学：

    • 消费者为什么愿意多付钱？

      可能是因为：降低信息不确定性。

      例如：“这家店虽然贵，但不会坑我。”

综合以上所有看法，配合证据可靠性的不同权重，我们才能真正了解到它为什么卖这么贵。

世界是复杂的，要多角度地看；世界是变化的，得以能更新的方式去识别它。

回到现实

关于刚刚咖啡卖30元的例子，它的重点在于，你的思考最终要回到“为什么卖这么贵”上，如果你从马克思的劳动价值理论想到是万恶的资本家干的，于是喊出“真该把资本家吊路灯”，那就偏离了。

在心理学上，有个概念叫灾难化想象，一些人会持续地往坏处想，幻想错一步就会步步错，引发巨大的灾难性后果。它的内耗过程就是在一直思考，但思考的都是无法与现实产生互动的事：比如他为什么那么看我，我刚刚做错什么了，我都搞啥了，会不会是那次……就一直想一直内耗。

如果掺入一点斯多葛主义的核心理论——区分“我能控制什么”和“我不能控制什么”，然后把主要的思考和行动资源放在前者上——那就可以跳出这个反刍内耗的循环了。

可以想到接下来能做点什么，比如跟他确认一下是不是有什么事，是不是要跟他打好关系，我以后是不是要注意一下自己的行为。

这个回到现实不只是在思考的最后，有时就连思考前就得考虑现实了，具体来说就是要分场景。

在法律、合同这类场景，字面定义、术语边界、责任范围必须被严格控制。我们不能再把“理解文字背后的思想”当成优先目标；这在法律与合同这个场景下是行不通的。

求职面试时，人事与面试官会采用那套从学历专业、工作年限、项目经历、上份薪资、证书、面试表现就简单判断一个人能力的模型。你可以认为它不是评价人的最佳模型，但它就是当前招聘场景实际在用的模型。

公司在招聘工程师时，比起“我理解这套系统背后的底层理论，知道哪里找到最新最准确的部署文档，擅长灵活变通”的人，也会更倾向于找“这套东西我部署过 50 遍了，在记事本上都能手写配置命令”的人。这并不意味着后者一定比前者更优秀，而是因为在这个具体岗位、具体场景下，稳定、熟练、低错误率的执行能力本身对公司而言就是价值。

什么时候该怀疑、什么时候该相信；什么时候该重新建模，什么时候直接调用一个已经足够可靠的模型；以及哪些思考该停下来——那些已经产生不了新信息、改变不了现实、也指导不了行动的思考。

我反对什么

到这一篇已经基本足够代表我目前的思想了，甚至我工作上的排查故障思维也是如此。我从不盲目相信经验/直觉就断定故障原因，而是多了解现象以及多次尝试验证假设。关于这方面，以后大概会单独写一篇。

事实上，我所有文章以及我的个人理念中最最核心的一条就是尊重主体性，解放主体性。

我反对：

  • 看到一个经济现象，就直接套用某个主义；
  • 看到一个人的行为，就直接套入某个心理学模型；
  • 看到自己的情绪，就直接套入某个心理学标签；

这些行为，表面上看是自己在做思考，实际上可能是理论模型替我完成了判断。

就像在这个 AI 大流行的时代，有个自嘲式说法，AI 取代了人脑，人成为 AI 的行动工具。

我不希望别人未经我同意就替我决定人生，因此我也尽可能不未经他人同意替他决定人生。这也是我常被认为边界感过于强烈，不近人情的原因之一。

前面提到的动漫《异国日记》，女主起初也是不喜欢小姨。

也因此，我不要求任何人“必须”按我的来，不会直接告诉任何人“你要怎么做”，我只提供一个“你可以试试”的建议。只有当我察觉对方可能走入误区时，才会拦一下。可这种干涉他人的行为本身就跟我的理念冲突，导致我每次这么干时，心里总不太舒服。这些人际交往中的困境都是我未来需要自己面对与克服的。

再更：好为人师

最近有了点新领悟，但内容不多，就更在这里了，算是对本文的进一步补充，也是写给我自己的。

我们总会有一种克制不住的冲动——好为人师。

更具体地说，就是：“如果我知道某种东西可能对他有帮助，那么我就应该把它告诉他。”

但人与人相处并不是这样简单的因果关系。

  • 人很难仅仅通过几次聊天改变另一个人的深层观念；
  • 日常交流不是哲学讨论会，很多时候大家只是在聊天；
  • 对方没有主动请求帮助时，你的“纠正”很容易被理解成说教；
  • 即使你的建议确实有道理，对方也可能暂时不需要、不同意，甚至根本不想听。

一个人只能以他自己的速度、自己的方式生活，包括犯一些我们认为完全可以避免的错误。

尊重主体性，落到日常就是克制住想管人的冲动。

我们大概都经历过这样的事情：“我是为了你好。”然后对方就替你决定应该怎么生活，强迫你去做某件事情。

放下

对我来说，我知道上述道理，但正因为我知道得越来越多，也学习了社会学、经济学、心理学和哲学，我越来越容易看见问题：

  • 个人痛苦背后的结构；
  • 内耗背后的心理机制；
  • 教条背后的社会规训；
  • 贫困背后的制度与经济结构；
  • 人际冲突背后的主体性问题。

但这种看见问题会给我带来一种艰难的困境，我无法替朋友解决问题，也无法改变朋友那些已经根深蒂固的思维方式。同时，如果我执着于“为了他好”而试图强行改变他，那么我就很容易从朋友变成纠正者，变成一个试图替他决定人生的人。

这种“想帮，却帮不了”的矛盾，反而会持续消耗我自己的精神，让自己也陷入内耗。

最近我开始接受一个对我来说很重要的理念：

对朋友最大的尊重，有时候不是把自己认为正确的东西塞给他，而是相信他有能力承担自己人生的后果。

现在我开始练习课题分离，并尝试从“纠正者”转变为“可提供资源的同伴”；我拥有一些知识、经历和观点，如果对方愿意，我可以提供给他。

课题可以分成三个部分：

  • 我的课题：我是否愿意表达、我怎么表达、什么时候介入，以及能否接受别人不同意我。
  • 对方的课题：他听不听、信不信、怎么理解、是否改变，以及最终怎么生活。
  • 共同的部分：如果对方明确邀请我讨论，那么我们可以共同分析；但最终决定权仍然属于对方。

陪伴

因此，当朋友陷入失意时，我会：

  • 提供一个观点；
  • 分享一个经历；
  • 告诉他一个自己认为有用的概念；
  • 必要的时候提醒一个明显的风险。（被骗/自毁倾向时）

同时做到保持距离，他没有明确需要的时候，不强迫他，不强迫他听，也不因为自己“知道更多”就不断解释。

当他说：“算了，我自己想想”或者“这些我都知道，但我就是 XXX”以表示话题结束或不想深入谈论道理时，就放下。只需要告诉他：“如果你想聊，我在。”然后把选择权还给他。

模式一：发现问题 → 陪伴 → 询问 → 等待 → 对方需要时再分析。

模式二：发现问题 → 分析问题 → 解释问题 → 提供解决方案。

对于日常人际关系而言，第一种模式往往更合适。因为它更具有人文关怀，这时候，我们不是“好为人师”的上位者/长辈在教他做事，而是一同前行的伙伴。

主体性与影响

我主张尊重人的主体性，可这种主张本身常让我陷入两难。

在群聊里，大家经常使用一些非常简单的说法去解释复杂的问题：“想开点”、“社会就是这样”、“躺平就完了”。

这些话有时候当然可以作为一句安慰或一种经验判断。但如果它们被当作对复杂现实的完整解释，就可能把本来存在的多种可能压缩成一种答案；甚至导向“你没得选择、你改变不了”这种对主体性的扼杀。

在这种时候，我为了不影响他人的主体性，选择沉默，那就可能导致他人的主体性被影响；我出来干预，我就成了影响他人主体性的人。

这种两难困境折磨了我很久，现在，我想也许我该进一步修正旧有认知，影响并不等于主体性的丧失。

人生在世，本就时刻被外界影响，周围的人际关系、社会秩序、书籍媒体等等。主体性不等于“不被影响”，而是一个人面对各种影响时，能否持有自己的思考与选择。

所以在群聊里，当一个人只能听到一种声音时，给他提供第二种声音，也许能扩大一点他的选择空间。

不过，这也要审时度势，M01 中的【与人】一节谈到的观点：

绝大多数人的日常交流，是基于情绪、身份认同和社会直觉，而不是逻辑推演；绝大多数亲密关系依赖的是共情和共同记忆，而不是共识。

在群聊里，很多时候不必长篇大论地展开，给人上课。如果群里的人明显不感兴趣，那就及时沉默。

如果有人反驳你，也该考虑要不要回应、怎么回应。通常也不必长篇大论，打哈哈、表示纯属个人观点，或者转移话题就行。（群聊不是辩论会）
